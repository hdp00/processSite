- 审查修复完成后补充单元、HTTP 边界、SQL Server 集成和前端工具测试，并执行完整自动化测试门禁。

## 4. 已确认的处理结果

用户已确认当前数据库没有必须保留的真实业务数据，因此采用以下简洁方案，不增加历史迁移和回填分支：

1. **CR-006 Outbox 原子写入**：任务激活和流程完成时，在业务事务内冻结通知配置、收件人邮箱和模板数据并创建 Outbox；后台发送器仅领取并发送已有消息，不扫描业务状态补建，也不回填历史邮件。
2. **CR-007 大数据导出查询**：按当前发布版本字段导出，历史实例缺少字段时留空；权限、筛选、排序和 10001 行上限探测在 SQL 中完成，不把日期范围内的全部实例先加载到内存。

审查发现的 22 项问题均已处理。

## 5. 修复与验证记录

### 5.1 已完成修复

- 富文本统一使用 DOMPurify 标签、属性和协议白名单，继续兼容本地图片/视频占位协议。该依赖能明显减少自研过滤逻辑，因此新增 `dompurify` 并锁定版本。
- 自由协作详情、回复、回复附件、回复并变更受理人、参与人列表和 Mock/远端适配链路已贯通；权限判断回归业务规则，由领域服务校验参与人、发起权限组或受理权限组资格。
- 后台邮件任务支持过期租约回收，按最旧优先扫描，重试节奏统一为 1/5/15/60/360 分钟、累计 6 次死信；健康接口现在反映实际循环成功/失败状态。
- 任务激活和流程完成的邮件 Outbox 与业务状态在同一事务中创建并冻结收件人快照；后台发送器已移除业务状态扫描和补建逻辑。
- SMTP、LDAP、分页、日期边界、下载文件名、附件安全响应头和失败清理的异常边界已加强。
- 导出显示正式版本标签和选择项业务名称；回复编辑不再保留旧正文；README、Mock 文档和实施清单说明已同步。
- 流程清单导出的实例权限、文本/动态字段筛选、多字段排序和 10000 行限制均在 SQL 查询阶段完成，避免先加载全部实例和表单 JSON。
- 通过 pnpm override 将 `exceljs` 间接依赖的 `uuid@8.3.2` 提升到无公告版本，生产依赖审计恢复为 0。
- 修复 Orval 并发清理竞态和 Ant Design 6 弃用属性；C# 代码已统一格式化。
