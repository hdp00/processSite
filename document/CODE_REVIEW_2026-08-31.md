## 4. 安全与可靠性复核

- 富文本：最终渲染只使用 DOMPurify 白名单净化后的内容；链接补充 `noopener noreferrer`，本地媒体只允许受控引用。
- SQL：业务参数通过 EF Core 插值参数或显式 `SqlParameter` 传入；动态建库/删库使用 `QUOTENAME`，删除前还校验 `_WorkflowTests_` 命名约束。
- 配置：真实本地配置和凭据不在 Git 跟踪范围；代码库仅保存示例值，结构版本和内置 Seed 版本由代码统一定义。
- 附件：大小、扩展名、内容签名、路径、Range、生命周期和清理已有服务端验证；本轮补齐编辑场景临时文件回收。
- 会话：正式模式使用同源 HttpOnly Cookie，不把访问令牌保存到前端；CSRF、Host 和可信代理边界保持集中处理。
- 错误：前端统一经过 `ApiError` 和中文错误规范化；页面未新增直接 `fetch` 或绕过远端 DTO 适配的调用。
- 浏览器存储：生产代码没有清空整个 `localStorage`，只维护 FlowPilot 自有键并兼容旧结构。
- 依赖：NuGet 全部直接/间接包未发现已知漏洞；npm 生产依赖未发现已知漏洞。

## 5. 可读性与维护性复核

- 新增逻辑复用现有 `ExcelPdfPreviewModal`、`convertXlsxToPdf` 和附件 API，没有引入第二套实现或新库。
- 临时附件筛选提取为单一纯函数，并为 `temporary`、`active`、`cleanup-pending` 和空列表补测试，避免页面内重复生命周期判断。
- SQL 全链路测试虽然配置较多，但配置集中在一个明确场景中，主流程按创建、保存、发布、发起、处理、核对顺序排列；测试辅助类只增加隔离数据库和测试实体创建能力。
- 静态搜索未发现 `TODO/FIXME/HACK`、`NotImplementedException`、`@ts-ignore`、生产环境 `localStorage.clear()` 或未经净化的富文本渲染。
