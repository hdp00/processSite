# FlowPilot 页面视觉与交互统一规范

> 版本：1.0  
> 日期：2026-08-19  
> 适用范围：登录、员工工作区、流程配置、用户与权限、系统运维、表单设计器、流程设计器、打印页

## 1. 改造目标

- 保持企业内网后台应有的信息密度，减少装饰性渐变、重阴影和重复说明。
- 相同功能使用相同布局、间距、文案和操作位置，让用户形成稳定预期。
- 列表页、详情页和设计器采用不同的合适布局，但共享颜色、圆角、控件高度、状态和反馈规则。
- 不改变已经确认的业务流程、权限和数据范围，仅调整视觉表现与操作编排。
- 桌面端以 `1440 × 900` 为主要设计尺寸，保证最低 `1180px` 宽度下仍可完成全部操作。

## 2. 视觉基线

### 2.1 色彩

- 页面背景：`#F3F5F8`，不使用大面积放射渐变。
- 内容表面：`#FFFFFF`。
- 主文字：`#182238`；辅助文字：`#667085`；弱提示：`#8B95A7`。
- 主色：`#3659E3`，用于主按钮、当前导航、链接和焦点状态。
- 边框：`#E1E6EE`；弱分隔：`#EDF0F4`。
- 成功、警告、错误、关闭等业务状态统一通过 `StatusPill` 表达，不在页面中自行定义颜色。

### 2.2 圆角和阴影

- 普通卡片圆角 `12px`，输入控件和按钮圆角 `8px`，抽屉与弹窗圆角遵循 Ant Design 主题。
- 普通内容卡只使用细边框和极轻阴影；悬停卡片允许轻微提升，但不得大幅位移。
- 查询卡、表格卡、详情卡不再使用顶部装饰线、光晕或多层渐变。

### 2.3 间距

- 页面区块间距：`20px`。
- 卡片标准内边距：`20px`；复杂表单：`24px`。
- 表单项纵向间距：`18px`，查询区底部保留完整 `20px` 空间。
- 表格工具栏高度约 `64px`，数据行保持中等密度。

## 3. 页面结构

### 3.1 全局壳层

- 左侧导航保持深色，移除过重光晕；一级菜单图标、文本起点和选中状态统一。
- 顶栏只显示当前页面标题、演示身份和账号入口，不在内容区重复页面标题。
- 普通页面内容最大宽度保持一致；设计器使用全宽全高工作区。

### 3.2 列表页

统一结构为：

1. 可选的简短业务提示；
2. 查询卡；
3. 内容卡工具栏；
4. 标准数据表格和分页。

- 查询区只放常用条件；高级条件折叠。
- 查询和重置按钮位于查询行右侧或末尾。
- 表格操作列固定在右侧；查看、编辑、复制、打印、启停使用统一图标按钮和 Tooltip。
- 长文本单行省略并提供完整悬停内容；空值统一显示 `—`。

### 3.3 详情与审核页

- 顶部摘要只展示实例编号、状态、流程与版本、发起人和时间等关键内容。
- 流程进度、流程表单、审批记录按独立区块排列。
- 表单采用 Ant Design 标准 Form；查看态不显示必填或可选文字。
- 当前可执行操作集中在固定操作区，危险操作与普通操作分开。

### 3.4 编辑页与抽屉

- 资源列表的新增和编辑优先使用右侧抽屉；危险确认使用 Modal。
- 抽屉标题区显示对象名称，右上角统一为“取消 / 保存”。
- 页面级编辑向导统一使用顶部步骤条及“上一步 / 下一步”导航。
- 存在未保存修改时统一显示状态并使用同一离开确认。

### 3.5 设计器

- 表单设计器与流程设计器保留“左侧资源 / 中间画布 / 右侧属性”三栏。
- 两个设计器的顶栏高度、步骤条、面板标题、边框、背景、滚动条和保存状态保持一致。
- 中间画布使用轻灰工作背景，面板使用纯白背景，减少卡片阴影。
- 属性面板中的分组、表单标签和操作按钮使用普通后台表单规范。

## 4. 组件规则

- 主操作：每个区域最多一个蓝色主按钮。
- 次操作：普通描边按钮；返回统一使用 `AppBackButton`。
- 图标操作：`32 × 32px`，默认透明背景，悬停使用浅蓝背景，不反转成大面积实心色。
- 页签：任务中心和部门管理统一使用 `app-mode-segmented`。
- 查询卡：统一类名 `query-card`；必须保留底部内边距。
- 内容卡：统一类名 `content-card`；表格卡内部不重复增加外层边距。
- 状态：统一 `StatusPill`，同一状态在所有页面保持相同尺寸和颜色。
- 空白、加载、无权限和失败：统一使用 Ant Design `Empty`、`Spin`、`Result` 和 `Alert`。

## 5. 页面分组改造清单

### 员工工作区

- 流程发起：压缩概览和流程卡，突出流程名称、类型和“发起”操作。
- 任务中心：统一顶部页签、流程分类、列表上下文和表格边界。
- 流程清单：统一查询卡、动态列、操作按钮和分页。
- 流程详情/审核：统一摘要、进度、表单、附件和审批操作层级。
- 自由流程：统一时间线事件、回复卡片、人员信息和关闭/重开操作。

### 流程配置

- 流程管理、版本列表：使用同一查询、内容卡和表格操作规范。
- 基本信息、初始表单、流程设计、发布：共享步骤条和编辑页顶栏。
- 只读版本详情：与流程详情使用一致的信息区块和状态样式。

### 用户与权限

- 用户、角色、流程权限组：统一查询—列表—编辑抽屉结构。
- 部门/职务：统一页签和列表工具栏。
- 权限管理：保留矩阵密度，强化模块分组、当前角色和未保存状态。

### 系统运维

- 实例监控、审计日志：统一只读提示、查询、表格和详情抽屉。

### 特殊页面

- 登录页保留品牌区，但减少背景装饰，强化登录卡清晰度。
- 打印页以黑白信息完整和分页可靠为目标，不套后台卡片阴影。

## 6. 验收标准

- 同类页面的查询区、表格、页签、状态、操作按钮和抽屉视觉一致。
- 页面内容没有重复标题、重复账号信息或无意义说明。
- 查询控件与卡片底边之间保持明确留白。
- 关键操作位置稳定，图标按钮均有 Tooltip 和可访问名称。
- 设计器三栏在最低支持分辨率下可滚动且不裁切组件。
- 正常、空数据、校验失败、无权限和不同身份页面均保持可读。
