## 3. 流程定义配置矩阵

新增的领域生命周期测试逐项保存、发布、复制并锁定以下配置：

- 初始表单：固定标题、单行/多行文本、富文本、下拉、多级下拉、单选、复选、附件、表格、审核人字段。
- 字段属性：名称、说明、提示、默认值、必填、发起人/审核人输入阶段、任务中心显示、流程清单显示、查询和 Excel 导出。
- 选择与条件：普通及层级选项、AND 显示条件、选项默认值。
- 附件：大小、数量、扩展名、内嵌 PDF、Excel 转 PDF、最大页数。
- 表格：文本、下拉、单选、复选列，以及列必填、默认值、宽度、对齐和审核修改权限。
- 系统字段：任务中心、流程清单和导出显示的不同组合。
- 流程图：节点位置、审批权限组、指定审核人、审批/确认模式、节点可修改字段、允许重复修改、AND 执行条件、仅重新提交驳回规则、审批节点和结束节点邮件通知。
- 生命周期：新版本复制、分区保存、自动校验、发布、实例锁定发布版本、表单值保存和任务生成。

真实 SQL Server 测试使用同一类完整表单和流程配置，并额外验证过期 revision 被拒绝、当前审核人收到节点激活邮件、流程完成后发起人收到完成邮件。

## 4. 流程操作链路与边界

现有测试与本轮新增用例合并覆盖：

- 流程定义创建、查询、复制、导入/导出、分区保存、校验、发布、取消发布、停用、删除及引用限制。
- 固定审批发起、指定审核人、并行/串行任务、通过、确认、驳回、重新提交、审核字段修改、关闭、复制已完成流程、乐观锁和幂等。
- 自由协作发起、锁定版本表单显示、回复、变更受理人、关闭、重开、编辑初始表单和参与人/时间线同步。
- 权限边界：匿名访问、普通用户、发起资格、审核/受理资格、关闭资格、超级管理员和模拟身份。
- 附件边界：扩展名、内容签名、大小、数量、Range、生命周期、替换和清理；Excel 原文件不上传，确认后只上传 PDF。
- 查询边界：空结果、分页、极端页码、日期范围、流程分类计数、动态字段筛选、导出排序和 10000 行限制。
- 并发边界：ETag/revision 过期、相同幂等键重放、相同任务重复提交、租约超时恢复和事务回滚。

## 5. 本轮新增测试

### 5.1 真实 SQL Server 生命周期

每次测试创建唯一的 `<当前库>_WorkflowTests_<GUID>` 数据库，执行全部正式 Migration 和内置 Seed，然后走完：

1. 创建发起人、审核人和用途明确的流程权限组。
2. 创建流程定义并保存完整表单。
3. 保存流程图并验证旧 revision 冲突。
4. 发布版本并由有资格用户发起。
5. 指定的当前审核人处理待办，实例进入完成状态。
6. 核对任务激活和流程完成 Outbox 收件人。
7. 仅在库名符合 `_WorkflowTests_` 安全约束时删除临时数据库。

该方案不删除只追加审计日志，也不依赖开发库事务回滚来模拟跨事务业务链路。第一次试跑中断留下的测试定义、测试权限组和测试用户已按精确名称、说明、零实例及 `TEST-` 前缀清理。

### 5.2 前端领域与组件

- 验证全部表单/流程设置在保存、发布、复制与实例锁定后无损保持。
- 验证附件开启 Excel 转 PDF 后 `.xlsx` 进入转换处理，旧 `.xls` 不进入。
- 验证自由协作发起、详情和编辑弹窗始终显示锁定版本的完整字段，不再回退旧固定表单。
- 验证 Excel 转换后的临时 PDF 在替换、移除或取消编辑时清理，已生效历史附件保持不变。
