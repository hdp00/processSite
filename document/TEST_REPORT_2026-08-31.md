# FlowPilot 全面测试报告（2026-08-31）

## 1. 结论

本轮已补充后端单元测试、HTTP 认证边界测试、真实 SQL Server 集成测试和前端工具测试，并完成当前工程定义的完整自动化测试门禁。全部测试通过，没有剩余的自动化测试失败项。

测试期间发现的结构清单版本错误、过期测试断言和 SQL 集成测试数据依赖问题已经修复。没有新增第三方依赖。

## 2. 新增测试

### 后端

- 登录失败限流：首次失败、达到阈值、窗口过期和成功登录后的清理。
- 后台任务健康状态：初始状态、成功状态和异常状态。
- 附件文件存储：写入、打开、删除、空路径和重复删除。
- 认证边界：18 组受保护资源在匿名访问时均拒绝请求。
- 邮件 Outbox：在真实 SQL Server 中验证事务内写入、去重和收件人快照。
- 流程实例导出：在真实 SQL Server 中验证权限过滤、动态字段筛选、排序和分页上限查询。
- 数据库迁移：自动使用独立测试数据库，并在事务回滚后验证全部迁移脚本。

### 前端

- 日期范围解析和非法日期边界。
- 流程实例编号的规范化和降级显示。
- Excel 导出文件名、动态列顺序和单元格内容。

## 4. 自动修复的问题

1. 数据库结构清单内容已包含后续迁移对象，但清单版本和资源文件名仍停留在 `202608260001`。现已统一为当前版本 `202608280003`。
2. SQL 脚本校验和及结构清单测试仍假定只有一个迁移。现已按迁移目录中的五个有序迁移验证。
3. 迁移集成测试缺少专用连接配置时会跳过。现可根据本地运行配置自动创建并复用空的独立测试数据库。
4. 新增 SQL 测试最初缺少真实外键所需的流程权限组，并在主记录保存前写入子记录。测试数据准备已调整为符合生产数据库约束的顺序。

## 5. 数据库测试隔离

- 业务 SQL 集成测试在事务中执行，并在测试结束后回滚，不保留测试业务数据。
- 迁移验证使用独立的空数据库，名称在当前运行数据库后追加 `_MigrationTests`；数据库会保留以便后续一键复用，但迁移测试本身回滚。
- 本轮没有清空或覆盖开发数据库中的现有业务数据。

## 6. 仍需真实环境验收的范围

LDAP、SMTP、IIS、Windows Service 以及真实企业账号/邮件系统的联调依赖部署环境和外部服务凭据，不能由本地测试替代。当前代码和自动化门禁已为这些环境验收做好准备。
